# Офлайн-режим и расширенная справка учителя

Дата: 27 сентября 2026 года. Статус: на согласовании.

## Назначение

Учитель один раз открывает сервис с подключением к интернету, а затем может на телефоне или компьютере без сети проверить ответ, увидеть полную шкалу ФИПИ-2026 и прочитать разборы примеров. Сохранённые работы и автосохранённый черновик остаются в браузере этого устройства. Два вида примеров — опубликованные разборы ФИПИ и специально составленные учебные случаи — явно различаются.

## Текущее состояние и источники

В приложении уже есть расчёт для письменных заданий 28 и 29 и устных заданий 1–3, сохранение в `localStorage`, перенос JSON-файлом и адаптивная страница справки. Данные `FIPI_2026` содержат описания всех уровней каждого критерия, но справка показывает только максимум и ноль. Примеры сейчас кратко пересказывают результат без подробного разбора по критериям. Приложение не кэшируется для автономной загрузки; ссылки на PDF требуют сети.

Источники правил и опубликованных разборов:

- [ФИПИ, письменная часть, 2026](https://doc.fipi.ru/ege/dlya-predmetnyh-komissiy-subektov-rf/2026/kit_yaz_pch_mr_ege_2026.pdf): шкалы на с. 140–141; разборы ответов, в частности, на с. 98–105 и 119–128.
- [ФИПИ, устная часть, 2026](https://doc.fipi.ru/ege/dlya-predmetnyh-komissiy-subektov-rf/2026/kit_yaz_uch_mr_ege_2026.pdf): шкалы на с. 85–87; разборы вопросов и устных высказываний в основной части пособия.

Указанные номера — страницы самого PDF, используемые в ссылках `#page=`. Текст справки сверяется с этими источниками; если краткая формулировка в коде расходится со шкалой, уточняется и справка, и связанный расчёт.

## Выбранный подход

Приложение становится PWA: сборка включает веб-манифест и сервис-воркер с версионированным кэшем оболочки приложения. Кэшируются HTML, JS, CSS и локальные значки. Страницы справки и их данные уже входят в сборку, поэтому работают после успешного первого открытия без сети. Навигация приложения в автономном режиме возвращает кэшированный HTML; новые версии ресурсов загружаются при появлении сети и применяются без принудительной перезагрузки открытой проверки.

Альтернативы рассмотрены и не выбраны: отдельная папка с PDF на телефоне не даёт встроенной шкалы рядом с расчётом; полноценная серверная синхронизация не нужна для автономной работы одного устройства и меняет модель хранения работ.

Для установки и работы сервис-воркера на телефоне нужен HTTPS-адрес. Разработка на `localhost` допускает проверку на компьютере. Публикация сайта и синхронизация устройств не входят в эту задачу. До первого успешного открытия с сетью автономная загрузка невозможна; браузер также может удалить кэш или локальные данные при очистке хранилища. Экспорт JSON остаётся способом резервного копирования работ. Исходные PDF ФИПИ не кладутся в кэш: они объёмные и открываются только при наличии сети; в справке остаются название документа, страница и ссылка.

## Полные шкалы

На странице «Справочные материалы» учитель выбирает одно из пяти заданий. Для каждого критерия выводятся его код (К1–К4 или К1–К3), название, максимум и **каждый** уровень от максимума до нуля с условиями получения балла. Данные берутся из существующей структуры `FIPI_2026.criteria.levels`, чтобы справка и интерфейс оценивания не содержали две расходящиеся копии шкалы. Для задания 1 устной части показывается отдельное правило для каждого из пяти вопросов: 1 или 0 баллов; коды К1–К3 ему не приписываются.

Над шкалой показываются правила, влияющие на всё задание: пороги объёма письменных ответов, ограничение оцениваемой части при превышении объёма, условие непродуктивного ответа для задания 29 и обнуление остальных критериев при К1 = 0. Для устных заданий 2 и 3 указываются пороги числа фраз и обнуление при К1 = 0. Уровни не сокращаются до одного числового порога, если ФИПИ требует экспертного суждения о качестве или сочетании ошибок. Для пограничного решения остаётся ссылка на соответствующую страницу полной шкалы.

На широком экране критерии можно читать рядом с примерами. На телефоне они идут вертикально: заголовок критерия, далее компактные строки «балл — условие». Горизонтальная прокрутка всего документа не требуется.

## Разобранные примеры

Для каждого из пяти заданий справка содержит минимум один опубликованный разбор ФИПИ и один учебный случай. Опубликованный пример использует краткий фрагмент ответа или точное описание наблюдаемого признака, страницу пособия и **пересказ** аргументации ФИПИ; полный текст работы не копируется. Учебный случай содержит собственный короткий фрагмент ответа или конкретную ситуацию. Каждый пример сообщает, является ли фрагментом или полным ответом, чтобы читатель не принимал его длину за экзаменационный объём.

Разбор показывает: что требовалось, что фактически сказано или написано, отметки по релевантным аспектам, балл и объяснение по каждому оценённому критерию, итог и причину обнуления, если оно произошло. Для учебного примера, который иллюстрирует только один критерий, итог всей работы не придумывается: явно сказано, какие остальные критерии не оценивались. Для официального примера итог и баллы должны совпадать с опубликованным разбором. Отдельные примеры демонстрируют ноль за весь ответ из-за К1 или объёма и ноль только по одному из остальных критериев.

Примеры хранятся как типизированные локальные данные рядом с рубриками. Модель данных разделяет `official` и `educational`, ссылку и страницу источника, вид фрагмента, основания по критериям и результат. На экране видны пометка происхождения, название задания, оценка и раскрываемый разбор. Ссылки на источник остаются доступными онлайн; пояснения и фрагменты доступны офлайн.

## Данные и поведение при ошибках

Сервис-воркер кэширует только файлы приложения, не оценки учеников и не загружаемые пользователем JSON-файлы. Формат сохранённых записей и автосохранённого черновика не меняется. При отсутствии сети расчёт, редактирование, сохранение, поиск, печать и экспорт продолжают работать. Ошибка открытия PDF не затрагивает текущие отметки. Ошибку записи в браузерное хранилище приложение показывает так же, как сейчас; офлайн-режим не объявляется резервной копией данных.

Обновление справки может менять текст шкалы, но не должно молча менять версию критериев сохранённой проверки. Текущая версия остаётся ФИПИ-2026; переход на будущий год требует отдельной версии рубрик и отдельного решения.

## Проверка готовности

1. Для всех пяти заданий на странице есть каждый уровень каждого критерия, включая промежуточные баллы; коды критериев и исключение для устного задания 1 верны.
2. Десять или более примеров охватывают оба происхождения, а официальные баллы, основания и страницы сверены с пособиями ФИПИ-2026. Учебные случаи не выдаются за работы участников экзамена.
3. Тесты проверяют представление шкал и примеров, включая К1 = 0 и ноль только по отдельному критерию. При найденном расхождении данных и расчёта добавляется регрессионный тест для конкретного порога.
4. Production-сборка после одного успешного онлайн-открытия запускается с отключённой сетью: доступны проверка, справка, сохранённые работы и экспорт. Проверка повторяется с уже существующей записью и черновиком.
5. На узком экране (включая 320 CSS px) шкалы и примеры читаются без горизонтальной прокрутки страницы; интерактивные элементы доступны касанием и с клавиатуры.

## Вне объёма

Автоматический анализ текста или аудио ученика, копирование целых методических PDF в приложение, облачное хранение, синхронизация устройств и публикация на хостинге не входят в эту задачу.
