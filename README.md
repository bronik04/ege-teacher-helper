# Помощник проверки ЕГЭ по китайскому языку

Небольшое браузерное приложение для проверки заданий с развёрнутым ответом: письмо № 28, письменное высказывание № 29 и задания 1–3 устной части. Учитель отмечает аспекты содержания и ошибки, а приложение пересчитывает баллы по критериям ФИПИ 2026 года. Для каждого критерия есть короткая памятка и ссылка на полную таблицу.

## Запуск

Нужен Node.js и npm. В каталоге проекта выполните:

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`). Для проверки проекта: `npm test` и `npm run build`.

## Работа с проверками

1. Выберите задание и отметьте каждый аспект `+`, `±` или `−`. В задании 1 устной части отдельно засчитайте каждый из пяти вопросов.
2. Укажите объём ответа, ошибки и, где требуется, дополнительные признаки организации. Поля изначально не заполнены. Пока данных недостаточно, сумма помечена как **предварительная** и перечислены недостающие решения.
3. При неоднозначном сочетании отметок или пограничном качестве ответа сверяйтесь с полной таблицей ФИПИ и выберите балл в разделе «Экспертное решение». В задании 29 выбор уровня лексико-грамматического оформления обязателен: одинаковое число ошибок может соответствовать разным уровням языка. При нуле за решение коммуникативной задачи остальные критерии обнуляются.
4. При желании введите метку ученика и заметку, затем сохраните проверку. Незавершённую работу можно сохранить как черновик, открыть позже и продолжить.
5. В разделе «Сохранённые работы» можно скачать все проверки в JSON или импортировать такой файл. При импорте запись с уже существующим идентификатором пропускается без перезаписи. Повреждённый файл не меняет хранилище.

Текущая незавершённая проверка автосохраняется после каждого изменения и восстанавливается при повторном открытии страницы. Она не появляется в списке работ и не входит в экспорт JSON, пока вы не нажмёте «Сохранить проверку». Подтверждённый переход к новой проверке удаляет её временную копию.

Проверки хранятся **только в текущем браузере** (`localStorage`). Для другого устройства используйте экспорт и импорт. Файлы содержат отметки, метки и заметки; тексты ответов, фото и аудио сервис не сохраняет. Рекомендуется использовать псевдоним вместо имени ученика. Очистка данных браузера может удалить работы и автосохранённый черновик, поэтому экспортируйте нужные проверки.

## Источники и пределы

- [ФИПИ: материалы для предметных комиссий, письменная часть, 2026](https://doc.fipi.ru/ege/dlya-predmetnyh-komissiy-subektov-rf/2026/kit_yaz_pch_mr_ege_2026.pdf), таблицы на страницах PDF 140–141.
- [ФИПИ: материалы для предметных комиссий, устная часть, 2026](https://doc.fipi.ru/ege/dlya-predmetnyh-komissiy-subektov-rf/2026/kit_yaz_uch_mr_ege_2026.pdf), таблицы на страницах PDF 85–87.

Сервис считает первичные баллы только за эти пять заданий. Итог за экзамен и перевод в тестовые баллы не рассчитываются. Подсчёт не заменяет экспертное суждение учителя, когда шкала требует оценить качество ответа, соответствие уровню или существенность ошибки.
